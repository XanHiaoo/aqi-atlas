## 尚未完成，不能作为已验证发布版

1. **微信模拟器／真机运行**：开发工具 `islogin` 返回 `false`，未配置有效 AppID／测试号，CLI 导入被拒绝。需用户扫码登录并提供测试号或 AppID。
2. **真实微信数据直连**：当前执行环境访问 AQI.in 公开配置页返回 403，未鉴权搜索返回 401。网络适配器及错误处理已测试，但尚无微信真机上的成功网络证据。
3. **合法域名与数据源鉴权许可**：需在目标 AppID 后台确认第三方 HTTPS 域名配置，并取得适合客户端使用的有效访问方式。没有把本机 token 或私密 API key 打包。
4. **真实手势与微信层级**：拖动、Canvas 2D、弹层覆盖、原生 picker、文件分享和 iOS／安卓安全区仍需微信环境验证。Chromium 布局检查不能替代这些验证。
5. **上传、审核、发布**：未执行，当前不声称可以直接发布。

下一步由用户完成微信开发工具登录并提供 AppID／测试号后，继续从真实运行和网络检查开始；无需重新设计页面。
