# AQI Atlas 微信小程序设计稿

状态：原生工程已实现并完成计算、交互和编译模板布局检查，待微信运行时与真实直连验证。独立分支 `feat/wechat-miniprogram`，工程位于 `miniprogram/`，通过独立 PR 审阅。

## 目标与视觉

以当前网站手机版为母版，保留布局、文案、配色、统计口径与主要交互。采用微信原生小程序页面，适配微信胶囊按钮、状态栏和底部安全区。

- 背景 `#f4f7fb`，白色卡片，深蓝文字，浅蓝边线；不使用阴影。
- 沿用现有 AQI 连续色标及六档健康等级；差值图使用独立的蓝白橙色标。
- 默认进入日历，底部固定五个入口：**日历、实时、月历、统计、对比**。
- 页面保留紧凑实时数据栏，实时页使用完整卡片。顶部不重复展示城市名单。
- 来源与统计口径默认折叠，保留已精简的必要内容。

## 页面与交互

| 页面 | 展示内容 | 交互与布局 |
| --- | --- | --- |
| 日历 | 日期区间、实时数据条、AQI 图例、城市年度卡片 | 每城保留四项指标，全年按三列迷你月历展示；点击日值浮层显示城市、日期、AQI 和等级；无需展开月份 |
| 实时 | 已选城市的最新 AQI | 双列彩色卡片；明确区分快照、最新数据和过期缓存，记录更新时间 |
| 月历 | 城市 × 月份 | 月度中位数／良好日占比切换；固定三列城市宽度，不足三列保留空位，更多城市横向滑动；月份列固定；中位数不重复显示天数，良好占比显示良好天数／统计天数，无点击浮层 |
| 统计 | 日值累计分布、阈值占比 | 阈值滑块、≤50／≤100 快捷按钮、城市高亮及排序；多城市时支持锁定关注城市 |
| 对比 | 两城选择、差异指标、差值日历、月度差距、累计分布 | 支持交换城市；差值图例同时写明两座城市，随选择更新；日期点击展示两城原值和差值 |

### 城市管理

右上方“管理城市”打开底部弹层：搜索、勾选、删除、全选、清空、拖动排序。

- 使用独立拖动手柄，避免与勾选、删除和列表滚动冲突。
- 已选城市的顺序同步所有页面，并在重启后保留。
- 删除只移除用户列表中的城市，搜索后可重新添加。
- 手机客户端直接请求 AQI.in 完成联网搜索和新增城市；已有快照作为离线缓存，失败时保留已保存数据。

## 数据与计算

- 使用现有 AQI.in 美标 AQI-US 数据，不生成或替换观测值。
- 历史统计范围为过去 365 天，排除当天；日期按现有平台日期标签处理。
- 两城对比仅纳入共同有效日，缺失不填补，今日暂定值不参与。
- 与网站一致的共同有效日期、良好天数／统计天数默认规则不变。
- 直接复用公开快照的数据结构；优先复用或移植现有纯计算函数，并与网站输出逐项核对。
- 小程序使用兼容的 RGB 配色计算，保留网站 OKLab 插值方式和固定刻度，避免因平台差异改变颜色含义。

## 技术与目录规划

使用原生 JavaScript、WXML、WXSS；图表使用 Canvas 2D，月历使用原生布局。

```text
miniprogram/
  app.js / app.json / app.wxss
  pages/                 日历、实时、月历、统计、对比
  components/            导航、实时条、日历、图表、城市弹层、日值浮层
  services/              数据加载、接口适配、本地缓存
  utils/                 统计、日期、色标
  data/                  从现有公开快照导出的初始数据
  assets/                原生导航图标
  project.config.json    微信开发者工具工程配置
```

城市选择、排序、对比城市保存于小程序本地存储；小程序与浏览器的本地偏好各自独立。客户端直接请求数据源，无本项目服务器转发。跨设备偏好同步留到后续按需设计。

## 分阶段实现

1. **本地可运行版**：内置现有公开数据，完成五个页面、城市管理和图表。无需 AppID 或后端域名即可先进行代码检查及开发工具支持范围内的本地验证。
2. **联网版**：直接调用 AQI.in 日历、实时及搜索接口；加入缓存、失败重试、更新时间及过期状态。前台启动、恢复和日期变化时检查更新。已在微信模拟器临时关闭本机域名校验后，验证当前所选 7 城历史与实时更新成功。
3. **发布版**：已配置 AppID 并登录开发工具；仍需配置数据源合法域名及确认允许客户端使用的鉴权方式，再验证真机、上传和审核。无需先架设转发服务器。

小程序关闭后不承担后台定时采集任务，用户再次打开时直接检查并获取新数据。可选的共享快照仍可由现有 Actions 更新。
