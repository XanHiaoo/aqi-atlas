## 尚未完成，不能作为已验证发布版

1. **合法域名**：开启校验时，真实 `wx.request` 返回 `request:fail url not in domain list`。需用户在微信公众平台配置 `https://www.aqi.in`、`https://apiserver.aqi.in` 两个 request 合法域名，然后重新验证。临时关闭校验仅用于定位问题；团队配置仍启用校验。
2. **真机与数据源许可**：尚无微信真机成功请求证据；正式使用还需确认平台域名配置及数据源允许的客户端访问方式。没有把本机 token 或私密 API key 打包。
3. **设备交互**：微信模拟器中的触摸排序、Canvas 与弹层已验证；真机原生 picker、文件分享和 iOS／安卓安全区仍需检查。
4. **上传、审核、发布**：未执行，当前不声称可以直接发布。

下一步由用户完成合法域名配置，再验证开启校验的请求和真机预览；无需重新设计页面。
